# Preface

I have used Prolog intermittently since 1986 and have always appreciated its elegant approach to expressing computational problems as logical relationships. Prolog is more than a programming language: it is a way of thinking about computation that differs from imperative and functional styles. As AI spreads, Prolog's core strengths in symbolic reasoning, knowledge representation, and search make it more relevant than ever.

This book is a practical guide to building AI applications with Prolog. We mostly use SWI-Prolog, the de facto standard for serious Prolog work, with a closing chapter on the newer Scryer Prolog system. My goal is to show you how to combine Prolog's strengths (unification, backtracking, and declarative logic) with modern tools like large language models, knowledge graphs, and the semantic web to build real AI systems.

**Note: Dear reader, although I have been a Prolog enthusiast since the 1980s I have only four or five months of professional Prolog development experience. I used DeepSeek v4 (with some use of Gemini 3, and Claude Opus models) for developing and debugging the example programs and for editing the text for this book.**


## Who This Book Is For

I wrote this book for programmers who want to add Prolog to their AI work. You do not need prior Prolog experience since I include a tutorial chapter, but you should know at least one other programming language.

## How To Read This Book

If you are new to Prolog, read the first three chapters (Preface, Development Setup, and Tutorial) in order. After that, the chapters stand alone and you can jump to whatever interests you. Each chapter has runnable code examples in the book's GitHub repository.
