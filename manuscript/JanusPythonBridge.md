# The Janus Python Bridge

SWI-Prolog's Janus library provides a bidirectional bridge between Prolog and Python, enabling Prolog programs to call Python functions and vice versa. This opens up the entire Python AI ecosystem — including scikit-learn, spaCy, transformers, and PyTorch — to Prolog developers.
